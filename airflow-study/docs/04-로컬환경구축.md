# 04. 로컬 환경 구축

Docker Compose로 5분 안에 Airflow 학습 환경을 띄웁니다.

## 사전 준비

| 도구 | 버전 | 확인 |
|------|------|------|
| Docker Desktop | 20.10+ | `docker --version` |
| Docker Compose v2 | 2.0+ | `docker compose version` |
| 메모리 | **최소 4GB**, 8GB 권장 | Docker Desktop 설정 |
| 디스크 | 5GB 여유 | |

> Apple Silicon(M1/M2/M3)에서도 동작합니다. (이미지가 multi-arch로 빌드됨)

## 디렉토리 구조

```
airflow-study/
├── docker-compose.yaml   # 본 가이드의 compose 파일
├── dags/                 # DAG 파일들 (호스트 ↔ 컨테이너 공유)
├── logs/                 # 실행 로그
├── plugins/              # 커스텀 플러그인 (지금은 비워둠)
├── config/               # 설정 (지금은 비워둠)
└── docs/                 # 학습 문서
```

## 단계별 설치

### 1) `.env` 파일 준비

저장소에는 `.env.example`이 있고, `.env`는 gitignore되어 있습니다. 복사부터 합니다.

```bash
cp .env.example .env
```

`.env` 안의 `AIRFLOW_UID` 값을 호스트와 맞춥니다.

| OS | 값 |
|----|----|
| macOS | `50000` 기본 OK (Docker Desktop이 자동 매핑). bind mount 권한 충돌 시 `id -u` 권장 |
| Linux | `id -u` 결과값 (예: `1000`) **필수** |
| WSL2 | `50000` 권장 |

```bash
# Linux 또는 macOS에서 권한 충돌 시 (sed 형식이 OS마다 다르므로 주의)
# Linux:
sed -i "s/^AIRFLOW_UID=.*/AIRFLOW_UID=$(id -u)/" .env
# macOS (BSD sed):
sed -i '' "s/^AIRFLOW_UID=.*/AIRFLOW_UID=$(id -u)/" .env
```

### 2) DB 초기화 (최초 1회)

```bash
docker compose up airflow-init
```

다음과 같은 메시지가 마지막에 나오면 성공:

```
airflow-init-1  | User "airflow" created with role "Admin"
airflow-init-1 exited with code 0
```

### 3) 백그라운드 기동

```bash
docker compose up -d
```

### 4) 상태 확인

```bash
docker compose ps
```

기대 결과:

```
NAME                                STATUS
airflow-study-airflow-scheduler-1   Up (healthy)
airflow-study-airflow-webserver-1   Up (healthy)
airflow-study-postgres-1            Up (healthy)
```

> healthy까지 30~60초 정도 걸립니다. unhealthy로 시작했다가 healthy로 바뀝니다.

### 5) Web UI 접속

브라우저에서 다음 주소를 엽니다.

```
http://localhost:8080
```

로그인:

| 항목 | 값 |
|------|-----|
| Username | `airflow` |
| Password | `airflow` |

> 학습용이므로 기본 계정을 그대로 사용합니다. **운영 환경에서는 절대 그대로 쓰지 마세요.**

## 잘 됐는지 확인하기

1. **DAGs 목록** 화면이 보임 (학습용 DAG 4개)
2. 우측 상단에 **Airflow 2.9.x** 버전 표시

## 자주 막히는 부분

### 컨테이너가 unhealthy로만 떠 있다

```bash
docker compose logs --tail=200 airflow-scheduler
docker compose logs --tail=200 airflow-webserver
```

대부분 다음 중 하나:
- **메모리 부족**: Docker Desktop → Settings → Resources에서 4GB+ 할당
- **포트 충돌**: 8080이 이미 사용 중 → 다른 앱 종료 또는 compose의 ports를 `8081:8080`으로 변경
- **권한 문제 (Linux)**: `AIRFLOW_UID` 미설정 → 1) 단계 다시 수행

### DAG가 UI에 안 보인다

1. `dags/` 디렉토리에 `.py` 파일이 있는지 확인
2. 파싱 오류 확인:
   ```bash
   docker compose exec airflow-scheduler airflow dags list-import-errors
   ```
3. 30초 정도 기다리기 (Scheduler 파싱 주기)

### 모든 걸 초기화하고 다시 시작

```bash
docker compose down -v   # -v는 볼륨까지 삭제 (DB 초기화)
docker compose up airflow-init
docker compose up -d
```

## 컨테이너 안에 들어가기 (CLI 학습용)

```bash
# Scheduler 컨테이너 셸 진입
docker compose exec airflow-scheduler bash

# 컨테이너 내부에서
airflow dags list
airflow tasks list 01_hello_airflow
airflow info
```

CLI 명령어들은 [12. CLI 백필](12-백필-CLI.md)에서 자세히 다룹니다.

## 종료 / 재시작

```bash
docker compose stop          # 컨테이너 중지 (DB 데이터 유지)
docker compose start         # 다시 시작

docker compose down          # 컨테이너 삭제 (DB 데이터 유지)
docker compose down -v       # DB 데이터까지 삭제

docker compose restart airflow-scheduler   # 한 컴포넌트만 재시작
```
