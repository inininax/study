# 16. 매크로 함수

`{{ macros.* }}` 네임스페이스에서 호출 가능한 함수/모듈들. 날짜 계산이나 ID 생성에 자주 씁니다.

## 날짜 매크로

### `macros.ds_add(ds, days)`

ds 문자열에 일수를 더하거나 뺀 새 ds 문자열 반환.

```jinja
{{ macros.ds_add(ds, 1) }}     → 내일
{{ macros.ds_add(ds, -1) }}    → 어제
{{ macros.ds_add(ds, -7) }}    → 일주일 전
{{ macros.ds_add(ds, 30) }}    → 30일 후
```

```jinja
-- 어제 데이터를 다시 보고 싶을 때
WHERE event_date = '{{ macros.ds_add(ds, -1) }}'
```

### `macros.ds_format(ds, in_fmt, out_fmt)`

ds 형식 변환.

```jinja
{{ macros.ds_format(ds, '%Y-%m-%d', '%Y%m%d') }}        → "20260103"
{{ macros.ds_format(ds, '%Y-%m-%d', '%Y/%m/%d') }}      → "2026/01/03"
{{ macros.ds_format(ds, '%Y-%m-%d', '%Y%m') }}          → "202601" (월만)
```

> `ds_nodash` 예약어가 있으니 `'%Y%m%d'` 변환은 그냥 `{{ ds_nodash }}`로 충분.

## 모듈 직접 사용

`macros`는 사실상 **유용한 모듈을 묶어둔 네임스페이스**입니다. Python 코드처럼 메서드 호출 가능.

### `macros.datetime`

`datetime` 모듈 그대로.

```jinja
{{ macros.datetime.now().isoformat() }}
{{ macros.datetime.utcnow().strftime('%Y-%m-%dT%H:%M:%S') }}
```

> 단, **DAG 파일 최상위가 아닌, Task 실행 시점에 평가**됩니다.

### `macros.timedelta`

```jinja
{{ logical_date - macros.timedelta(days=1) }}
{{ data_interval_start + macros.timedelta(hours=6) }}
```

### `macros.dateutil`

`python-dateutil` 라이브러리.

```jinja
{{ macros.dateutil.parser.parse('2026-01-03').isoformat() }}
{{ macros.dateutil.relativedelta.relativedelta(months=1) }}
```

### `macros.uuid`

```jinja
job_id = "etl_{{ ds_nodash }}_{{ macros.uuid.uuid4() }}"
```

### `macros.random`

```jinja
{{ macros.random.randint(0, 100) }}
```

### `macros.hashlib`

```jinja
{{ macros.hashlib.md5(ds.encode()).hexdigest() }}
```

## 주의: 매크로는 Jinja 안에서만

매크로는 **Jinja Template 컨텍스트**에서만 호출 가능합니다. Python 코드 안에서 `macros.ds_add(...)`를 직접 부르면 NameError.

```python
# ❌ 안 됨
def my_func(**context):
    yesterday = macros.ds_add(context["ds"], -1)

# ✅ 됨 (datetime 직접 사용)
from datetime import timedelta

def my_func(**context):
    yesterday = (context["logical_date"] - timedelta(days=1)).strftime("%Y-%m-%d")
```

## 자주 쓰는 패턴 모음

```jinja
-- 어제, 7일 전
{{ macros.ds_add(ds, -1) }}
{{ macros.ds_add(ds, -7) }}

-- 1주 전 ~ 어제 구간
WHERE event_date BETWEEN '{{ macros.ds_add(ds, -7) }}' AND '{{ macros.ds_add(ds, -1) }}'

-- 월의 첫날 (ds가 이미 월의 첫날이라면 그대로)
{{ macros.ds_format(ds, '%Y-%m-%d', '%Y-%m') }}-01

-- ISO 주(week) 번호
{{ logical_date.strftime('%G-W%V') }}    -- 예: 2026-W01

-- 1분기 시작일 계산 (Python처럼)
{{ logical_date.start_of('quarter').to_date_string() }}    -- pendulum 메서드

-- 6시간 전 시각
{{ data_interval_start - macros.timedelta(hours=6) }}
```

## logical_date는 pendulum 객체

`logical_date` / `data_interval_*`은 일반 `datetime`이 아닌 [pendulum](https://pendulum.eustace.io/) `DateTime` 객체입니다.

```jinja
{{ logical_date.year }}                       2026
{{ logical_date.month }}                      1
{{ logical_date.day }}                        3
{{ logical_date.day_of_week }}                Saturday (6)
{{ logical_date.start_of('month') }}          2026-01-01 00:00:00+00:00
{{ logical_date.subtract(days=7) }}           1주일 전
{{ logical_date.add(months=1) }}              1개월 후
{{ logical_date.in_timezone('Asia/Seoul') }}  KST로 변환
```
