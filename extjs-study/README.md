## Ext JS 라이브러리 직접 설치 필요
- Ext JS는 상용/GPL 라이선스이므로 이 저장소에 포함하지 않습니다.
- 예제 실행 전 아래 버전을 직접 내려받아 해당 경로에 배치하세요.
  - `src/libs/ext-5.1.4/`
  - `src/libs/ext-6.2.0-gpl/`
