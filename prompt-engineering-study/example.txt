당신은 golang back-end 개발자입니다.
다음의 내용을 참고하여 front-end 개발자들이 사용할 chatting server 코드를 작성해 주세요.

--

[chatting server 정보]
- chatting server는 golang으로 작성합니다.
- chatting server는 2대 이상 구동될 수 있어 동시성을 보장해야 합니다.
- chatting server는 web socket 사용해야 합니다.
- chatting server는 redis 사용해 web socket에 연결된 사용자 정보를 redis에 저장하고 연결이 해제되면 redis에서 제거합니다.
- chatting은 동일한 Room에 속한 User들끼리만 가능합니다.



######



[golang struct example]
- User { Room_ID, Name }
- Room { User_ID, Name }
- Room_Users { Room_ID, []User }
- Message { Room_ID, User_ID, Text, Created_date }


[chatting message 송수신 조건]
- User가 Message 생성 시 Room_Users에 속한 []User에게만 Message 전송합니다.
- User들의 정보를 redis에 저장하여 Web socket에 접속해 있지 않을 경우 fcm push로 대신 Message 전송합니다.

--

- Chatting server는 golang으로 작성해야합니다.
- Chatting server는 Web socket을 사용합니다.
- Chatting server는 동시에 여러대가 구동될 수 있습니다. 동시성을 보장해야 합니다.
- Redis server는 1대만 구동됩니다.
- User는 ID, Name을 가지고 있습니다.
- Room은 ID, Name을 가지고 있습니다.
- RoomUsers는 Room, Users를 가지고 있습니다.
- Message는 Room, User를 가지고 있습니다.
- 동일한 Room ID를 가진 Users 끼리만 Message를 전송하고 받을 수 있습니다.
- 모든 ID는 int 입니다.
- Websocket으로 연결된 User 정보는 Redis에 저장합니다.
- Client의 web socket 연결이 끊어 지면 Redis에서 User 정보를 제거해야합니다.
