# 06. OOP Patterns - 객체지향 패턴

> 💡 **Java/Kotlin 개발자를 위한 핵심:**
> Python의 OOP는 Java보다 유연합니다. 진정한 private이 없고,
> 다중 상속을 지원하며, 덕 타이핑을 기반으로 합니다.

## 🎯 학습 목표

1. Python 클래스 기본 문법
2. 던더 메서드 (__init__, __str__ 등)
3. dataclass 활용
4. ABC vs Protocol 이해

## 🔄 다른 언어와 비교

| 구분 | Java | Kotlin | Python |
|------|------|--------|--------|
| 접근 제어자 | public/private/protected | 동일 | 관례 (_prefix) |
| 상속 | 단일 상속 | 단일 상속 | 다중 상속 |
| 인터페이스 | interface | interface | ABC, Protocol |
| Data class | record (14+) | data class | @dataclass |
