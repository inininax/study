# 중급 학습: 벡터 검색과 필터링 🔍

## 학습 목표

1. 벡터 검색 (Semantic Search) 마스터
2. 하이브리드 검색 (벡터 + 키워드) 활용
3. 고급 필터링 기법
4. 집계 및 통계 쿼리

## 필수 선행 학습

✅ 초급 모듈 (01-basics) 완료 필수

## 학습 순서

### 1️⃣ 벡터 검색 (`01_vector_search.py`)
**학습 시간: 1.5시간**

- Near Text: 텍스트 기반 유사도 검색
- Near Vector: 벡터 기반 검색
- Near Object: 기존 객체와 유사한 객체 검색
- 거리 측정 및 확신도 (certainty)

**핵심 개념:**
- 의미론적 검색의 힘
- 코사인 유사도
- 검색 파라미터 튜닝

### 2️⃣ 하이브리드 검색 (`02_hybrid_search.py`)
**학습 시간: 1시간**

- BM25 키워드 검색
- 벡터 검색과의 결합
- 알파 파라미터 조정
- 실전 사용 사례

**핵심 개념:**
- BM25 알고리즘
- 하이브리드 검색 최적화
- 검색 품질 향상

### 3️⃣ 고급 필터링 (`03_filters.py`)
**학습 시간: 1시간**

- Where 필터
- 복합 조건 (AND, OR)
- 범위 검색
- 중첩 필터

**핵심 개념:**
- 필터 연산자
- 쿼리 최적화
- 인덱스 활용

### 4️⃣ 집계 쿼리 (`04_aggregations.py`)
**학습 시간: 45분**

- 그룹화 및 집계
- 통계 함수 (평균, 합계, 개수)
- 메타 분석

**핵심 개념:**
- 데이터 분석
- 통계 추출
- 대시보드 구현

## 실습 방법

```bash
cd lessons/02-intermediate

# 각 파일을 순서대로 실행
python 01_vector_search.py
python 02_hybrid_search.py
python 03_filters.py
python 04_aggregations.py
```
